# Installation

Getting started with OGify is straightforward. You can install the core package and the templates package using your preferred package manager.

## Install Packages

Run one of the following commands in your terminal:

### npm

```bash
npm install @ogify/core @ogify/templates
```

### pnpm

```bash
pnpm add @ogify/core @ogify/templates
```

### yarn

```bash
yarn add @ogify/core @ogify/templates
```
